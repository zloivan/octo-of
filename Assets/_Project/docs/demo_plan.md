## Общее описание демо

**Что показываем:** Пролог + 1-й день.
- Показать цель (нарративная линия с женщинами)
- Показать противостояние с Джейсоном через последствия его воздействия (дух соперничества)
- Дать цепляющую концовку, усиливающую интригу

**Сеттинг:** Реднеки, Алабама, ферма в глубинке Америки.

**Продолжительность:** ~25–30 минут. 2 адалта.

**Адалты в демо:**
1. Адалт с доением Рокси (с мини-игрой)
2. Адалт с Эмили (передний двор, кресло-качалка)

**Механики, которые показываем:**
- Перемещение по карте
- Доение (мини-игра)
- Поинт-клик
- Квесты-задачи

> ⚠️ **Исключено из демо:** Журнал и шкалы подозрения/влечения убраны из скоупа. Реализуются в последнюю очередь (после релиза демо или при наличии времени).
