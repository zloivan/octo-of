# Механика "Перемещение"

## Общая информация

Сегменты свободного перемещения чередуются с линейным повествованием. Когда сюжетная сцена заканчивается, игрок оказывается на одной из локаций фермы и может свободно перемещаться, взаимодействовать с объектами и по желанию заходить в мини-игры. Как только все задачи необходимые для продвижения сюжета выполнены, автоматически запускается следующая линейная сцена.

## Связанные системы

- **Система квестов:** определяет, какие задачи нужно выполнить и в каком порядке, чтобы продвинуться дальше
- **Мини-игры:** часть интерактивных точек на локациях является входом в мини-игру
- **Поинт энд клик:** на локациях расположены небольшие интерактивные предметы.

## Схема UI

Локация представляет собой 3D-видео на весь экран. Поверх него расположены интерактивные элементы:

### Интерактивная точка перехода / объект:

- В обычном состоянии — тонкая обводка вокруг объекта на видео (дверь, предмет, зона)
- При наведении курсора — обводка ярче, рядом появляется подпись (название локации или игры), курсор меняется на "перемещение"
- При клике — переход на следующую локацию или запуск мини-игры

### Кнопка Назад:

- Фиксированная кнопка внизу по центру экрана
- Та же стилистика подсветки, что и у интерактивных точек
- Доступна только в локациях без сквозного выхода

## Карта локаций

Часть локаций становится доступна не сразу (например, мини-игры только после того, как они уже были в сюжете).

**ДВОР** (стартовая точка сегментов)
```
├── Дом ГГ (гостиная)
│   └── Манекен → мини-игра "Борьба"
├── Гараж
│   └── Выезд в город → переход (иногда может быть целью квеста)
└── Задний двор
    ├── Зона стрельбы → мини-игра "Стрельба"
    ├── Амбар
    │   ├── Загоны с козами → мини-игра "Контроль"
    │   └── Поле (переход)
    └── Поле
        ├── Трактор → мини-игра "Реакция", локация для адалта
        └── Амбар (переход)
```

Амбар, Поле и Задний двор соединены по кругу — игрок может обходить их в любом направлении.

**ГОРОД, стоянка у бара** (стартовая точка сегментов)
```
└── Бар
    └── Бильярд / столики
        └── Механический бык → мини-игра (доступна только в день фестиваля)
```

## Принцип работы

### Переход из сюжета в свободное перемещение

- Линейная сцена заканчивается, игрок оказывается на указанной в нарративе локации. Система квестов фиксирует, какие задачи необходимо выполнить в этом сегменте.

### Перемещение и взаимодействие

- Игрок наводит курсор на интерактивную точку перехода — видит подсветку и название локации либо мини-игры.
- По клику внутри зоны перемещения загружается следующая локация, воспроизводится звук `click_movement_forward`
- По клику внутри зоны "назад" загружается предыдущая локация, воспроизводится звук `click_movement_back`

### Сцены на локациях

- При входе на некоторые локации может автоматически запускаться короткая сюжетная сцена с диалогами и выборами
- После завершения сцены игрок остаётся на той же локации и продолжает свободное перемещение. Такие сцены могут как засчитывать пункт квеста, так и просто добавлять нарратив.

### Мини-игры тренировки

- Ряд интерактивных точек ведёт в мини-игры, не обязательные для продвижения сюжета — они доступны для тренировки перед фестивалем в любой момент.
- При входе в мини-игру игрок нажимает кнопку для старта
- Выход из мини-игры по клику на крестик

### Возврат в сюжет

- Как только выполнены все обязательные задачи текущего сегмента (или игрок пришёл в нужную локацию / сделал нужное действие) — автоматически запускается следующая сюжетная сцена.

# Механика "Поинт энд клик"

## Общая информация

На локациях свободного перемещения помимо точек перехода и входов в мини-игры есть интерактивные предметы, на которые можно кликнуть. Это точки интереса, которые наполняют локации деталями и делают пространство более живым. Часть предметов активна только в определенный сюжетный момент и связана с квестами, часть постоянно находится на локации и дает небольшие одноразовые бонусы при нахождении.

## Связанные системы

- **Свободное перемещение** — предметы расположены на локациях, доступных в сегментах свободного перемещения
- **Система квестов** — нахождение нужного предмета может быть пунктом квеста
- **Система шкал** — клик по предмету может дать бонус к одной из шкал

## Схема UI

- Интерактивные предметы выделены небольшим сиянием
- При наведении курсора на интерактивный предмет курсор переходит в состояние особого для предметов подсвечивания
- При клике на предмет около него воспроизводится небольшой визуальный эффект

## Принцип работы

- Игрок водит курсором по локации и замечает, когда курсор меняется.
- При клике в зоне интерактивного предмета воспроизводится диалог с реакцией ГГ и звук `click_object`
  - Если предмет квестовый, засчитывается пункт квеста.
  - Если предмет предполагает обновления других статов, они обновляются.
- Один и тот же предмет нельзя активировать дважды — после клика он полностью пропадает.

## Виды предметов

### Квестовые предметы

- Спаунятся на локации только когда игрок получает квест
- Нужны для прохождения соответствующего квеста
- Примеры: бутылки с алкоголем, ключи, инструменты/запчасти, потерявшаяся коза

### Секреты

- Спаунятся в начале игры и 1-2 раза в определенных сюжетных моментах.
- Не имеют влияние на сюжет, но при сборе всех можно дать игроку ачивку за исследование
- Примеры:
  - фотография героев из детства — дополнительный нарративный контекст
  - надпись на заборе — плюс к attraction определенной девушки, ГГ понимает что она оставила ему записку
  - забытые трусики — минус к suspicion определенной девушки, ГГ убирает "улику"
  - возможно какие-то монетки, чтобы было больше попыток поиграть в механического быка или что-то такое

# Механика "Квесты"

## Общая информация

В течение сегментов свободного перемещения игрок получает один или несколько квестов. Квест может состоять из нескольких действий и завершается только после выполнения всех. Когда все активные квесты выполнены, панель квестов закрывается и запускается следующая сюжетная сцена.

## Связанные системы

- **Свободное перемещение** — квесты направляют игрока между локациями. Завершение всех активных квестов автоматически запускает линейный сюжет.
- **Поинт-энд-клик** — часть квестов выполняется через взаимодействие с интерактивными точками на локации
- **Мини-игры** — прохождение мини-игры может быть пунктом квеста

## Схема UI

В левом верхнем углу экрана поверх 3D-локации отображается панель квестов с заголовком и иконкой.

- Каждый квест — это пункт с чекбоксом
  - Выполненный пункт отмечается галочкой и исчезает
  - Составной пункт показывает счётчик прогресса — например, Найти выпивку (2/3)
- Когда все квесты выполнены — панель исчезает полностью.

Панель не перекрывает интерактивные точки локации и не имеет кнопки закрытия.

## Принцип работы

- Квесты указаны в нарративе (ГД + НД) и выдаются автоматически при переходе из линейной сцены в сегмент свободного перемещения. Панель квестов становится активной на экране. Одновременно в панели может быть активно несколько квестов.
- Игрок выполняет квесты в любом порядке. При выполнении квеста он зачеркивается и исчезает, воспроизводится звук `quest_crossed`
- Квесты со счетчиком прогресса завершаются и исчезают, когда все действия выполнены. При выполнении одного действия воспроизводится звук `quest_ticked`
- Когда порядок важен, следующий квест становится видимым только после выполнения предыдущего — он добавляется вместо последнего выполненного.
- Когда выполнен последний пункт последнего квеста — панель исчезает, воспроизводится звук `quest_completed`, автоматически запускается следующая линейная сцена.

## Виды квестовых действий

- **Посетить локацию** — пункт засчитывается автоматически при входе на нужную локацию. Никакого дополнительного взаимодействия не требуется.
  - Пример: *"Заглянуть домой"* — игрок переходит в дом, если предусмотрен диалог, он проигрывается, затем пункт засчитывается.

- **Найти предмет (поинт-энд-клик)** — игрок обходит локации и кликает на интерактивные точки. Пример: *"Найти следы взлома"* — игрок проверяет локации, при клике на одну из дверей показывается статик со сломанным замком, проигрывается диалог, пункт засчитывается.
  - Пункт может требовать найти несколько предметов — тогда в панели отображается счётчик. Пункт засчитывается, когда найдено нужное количество.
  - Пример: *"Проверить заначки (2/3)"* — игрок кликает на места на локациях, где могут быть спрятаны деньги, счётчик растёт при каждом верном клике, может быть проигран диалог. После третьей находки пункт закрывается.

- **Сыграть в мини-игру** — пункт засчитывается после завершения мини-игры, вне зависимости от результата.
  - Пример: *«Сыграть в мини-игру Стрельба»* — игрок заходит в зону стрельбы на заднем дворе, проходит мини-игру, пункт выполняется.

# Механика "Шкалы соблазнения"

## Общая информация

У каждой девушки есть две независимые шкалы. Шкала влечения (attraction) отражает насколько девушку привлекает ГГ. Шкала подозрения (suspicion) отражает насколько связанные персонажи будут пытаться помешать ГГ и каждой девушке. Состояние шкал влияет на нарративные сцены флирта* и микроразветвления внутри адалта: дополнительные статики и (редко) стейты анимаций, альтернативные реплики, доступные выборы.

*под флиртом подразумеваю моменты сближения в нарративе отдельные от адалтов

## Связанные системы

- **Поинт-энд-клик** — найденные предметы могут дать небольшой бонус к Attraction или снизить Suspicion
- **Мини-игры** — результат мини-игры влияет на Attraction и Suspicion

## Схема UI

- Шкалы располагаются в верхнем углу экрана поверх 3D-сцены. У каждой шкалы горизонтальная полоска прогресса, своя иконка и цвет.
- Каждая кнопка выбора содержит небольшую иконку-индикатор справа от текста, показывающую эффект выбора
  - Пример: ATT↑↑ SUS↑
- Если действие заблокировано из-за проверки шкалы, заблокированная опция отображается в списке вариантов, но визуально затемнена. Рядом располагается короткая подсказка с причиной блокировки
- Шкалы отображаются на экране только в моменты выборов, которые повлияют на них либо доступны благодаря ним (проверка). В остальное время статистику шкал можно посмотреть в интерфейсе журнала.

## Принцип работы

- При первом появлении девушки в сюжете обе её шкалы устанавливаются на 2/10 (возможно настраивать, если не сможем вписать все выборы в сюжет)

### При диалоговом выборе:

- Игрок видит два варианта реплик с индикаторами.
  - **Рискованный выбор:** +2 ATT / +1 SUS
  - **Осторожный выбор:** +1 ATT / −1 SUS
- При клике на один из выборов параметры соответствующих шкал меняются мгновенно, воспроизводится один из звуков: `scale_risky` или `scale_conscious`
- Полоски шкал плавно заполняются или убывают до нового значения.

### После мини-игры:

- По окончанию мини игры поднимается либо шкала attraction, либо suspicion
- Шкала появляется в верхнем углу на несколько секунд
- Полоски соответствующей шкалы плавно заполняются или убывают до нового значения:
  - **Успех:** +1 ATT
  - **Провал:** +1 SUS
- Воспроизводится звук роста шкалы `scale_neutral`

### Проверки шкал:

- Проверка может быть частью флирт-сцены в нарративе или адалт-сцены.
- Система проверяет текущие значения ATT и SUS
- Если значения влияют на возможность выбора игрока, соответствующий выбор закрывается либо добавляется.
- Если от игрока не требуется выбор, просто воспроизводятся соответствующие значению реплики и статики.

## Схема развития шкал девушек

- У Грейс, Эмили и Рокси 4 выбора за игру, 2 мини-игры и 2 проверки с разветвлениями
- У Ханны 6 выборов, 2 мини-игры (встроены в адалт) и вместо проверок 3 адалта с различиями

### Схема обычной девушки

- Старт: ATT 2, SUS 2
- Выбор 1 (возможный ATT 3-4, SUS 1-3)
- Выбор 2 (ATT 4-6, SUS 0-4)
- Мини-игра 1 (ATT 4-7, SUS 0-5)
- **ФЛИРТ-ПРОВЕРКА 1** *(переменная может настраиваться)*
  - SUS 0–2 → сцене ничего не мешает
  - SUS 3–5 → связанный персонаж пытается помешать сцене
  - ИЛИ
  - ATT 4-5 → девушка осторожна
  - ATT 6–7 → девушка открыта, дополнительные статики
- Выбор 3 (ATT 5-9, SUS 0-6)
- Выбор 4 (ATT 6-11, SUS 0-7)
- Мини-игра 2 (ATT 6-12, SUS 0-8)
- **ФЛИРТ-ПРОВЕРКА 2**
  - SUS 0–4 → сцене ничего не мешает
  - SUS 5–6 → связанный персонаж пытается помешать сцене
  - SUS 7–8 → сцена заканчивается раньше
  - ИЛИ
  - ATT 6-9 → девушка участвует но не разгоняет сцену
  - ATT 10+ → девушка инициирует сцену

### Схема Ханны

- Старт: ATT 2, SUS 2
- Выбор 1 (возможный ATT 3-4, SUS 1-3)
- Выбор 2 (ATT 4-6, SUS 0-4)
- **ФЛИРТ-проверка** — герои в машине везут быка на продажу (ATT 4-7, SUS 0-5)
  - SUS 0–2 → сцена спокойная, ГГ контролирует ситуацию, мини-игра легкая
  - SUS 3–5 → сцена более напряженная, может быть вставка где друг подходит к двери и что-то спрашивает, мини-игра сложнее
- Выбор 3 (ATT 5-9, SUS 0-6)
- Выбор 4 (ATT 6-11, SUS 0-7)
- **АДАЛТ 1** — ГГ действует скрытно от друга, но тот находится в комнате (новый адалт не в синопсисе сейчас) — мини-игра на контроль
  - SUS 0–3 → все проходит незаметно
  - SUS 4–7 → друг что-то чувствует, оборачивается
- **АДАЛТ 2** — без мини-игры, проверка под вопросом
- Выбор 5 (ATT 7-13, SUS 0-8)
- Выбор 6 (ATT 8-15, SUS 0-9)
- **АДАЛТ 3** — друг застает девушку и ГГ вместе, мини-игра на баланс — мини-игра на силу, по итогам разветвление
  - Мини-игра 2 (ATT 8-16, SUS 0-10)
    - SUS 0–6 → друг морально сломлен и остается просто смотреть
    - SUS 7–10 → друг в бешенстве, но унижен и вынужден участвовать как саппорт

# Мини-игры: Общая информация

## Общая информация

Мини-игры — короткие интерактивные вставки, которые прерывают линейное повествование. Запускаются автоматически по сюжету или во время адалт-сцены с Ханной. Также доступны в любой момент сегмента свободного перемещения как тренировки. Могут задействовать точность, реакцию или выполнение действия. Независимо от контекста и механики, структура каждой мини-игры одинакова.

Каждая из четырех игр задействована минимум 2 раза — всего минимум 8 "появлений". Тренировки в свободном перемещении не считаются появлениями.

| Ссылка | Принцип игры | Локация на ферме | Вариации в сюжете |
|--------|--------------|------------------|-------------------|
| Стрельба (меткость, accuracy) | Точность | Задний двор — банки | День 5 тренировка Грейс; Бирпонг с кем-то из девушек; *Ферма: тренировочное стрельбище* |
| Борьба (сила, strength) | Реакция | Дом ГГ — манекен | День 3 Адалт 1 с Ханной (не вызвать подозрение пока друг за стенкой); День 6 борьба в грязи на фестивале; *Ферма: тренировка с манекеном* |
| Контроль (control) | Удержание баланса | Амбар — загоны козы | День 2 доение Рокси; День 7 Адалт 2 с Ханной (механический бык); *Ферма: доение коз в амбаре* |
| Реакция (reaction) | Менеджмент | Поле/гараж — трактор | День 3 управление трактором с Эмили *(либо мб саботирование трактора Джейсона?)*; День 4 мытье машины Рокси; *Ферма: катание на тракторе или квадроцикле* |

## Связанные системы

- **Шкалы соблазнения** — 2 тренировки на каждую девушку влияют на ATT/SUS
- **Система квестов** — прохождение мини-игры может быть пунктом квеста

## Схема UI

Мини-игра открывается в отдельном UI-окне поверх сцены. Во время мини-игры игрок взаимодействует только с элементами внутри этого окна — всё остальное недоступно. После прохождения мини-игры открывается окно победы либо поражения:

### Окно победы:

- Заголовок
- Результат в очках (если есть счёт)
  - если побит рекорд соответствующая надпись
- Кнопка "Дальше"

### Окно поражения:

- Заголовок
- Результат в очках (если есть счёт)
  - индикатор, сколько нужно было набрать очков, чтобы пройти мини-игру
- Кнопка "Retry" перезапускает мини-игру с начала
- Кнопка "Skip" продолжает игру без награды

### Окно туториала

(появляется при первом запуске каждой механики)

- Название мини-игры
- Картинка или видео с объяснением, как играть
- Текст туториала
- Кнопка "Далее"

Когда игра запускается в режиме свободного перемещения в последующие разы, вместо туториала игра просто на паузе, игрок нажимает кнопку "Start" чтобы начать.

После этого на том же месте появляется кнопка "Skip"

Во время нажатия любых кнопок мини-игр (start, skip, next, retry) воспроизводится короткий звук `minigame_button`

### Таблица рекордов

**Рекорды (слева)**

- В верхней части вкладки с 4 мини-играми
- Игрок переключается между ними, контент таблицы рекордов меняется под выбранную игру
- Таблица показывает топ-5 NPC результатов (их очки не обновляются)
- Если результат игрока ниже топ-5 → он отображается как 6 место
- По мере улучшения результата игрок поднимается вверх по списку, вытеснив последнего NPC

**Награды (справа)**

- Адалт-статики с наградой в закрытом и открытом состоянии
- Условие разблокировки (Займите первое место в игре «название игры»)

## Принцип работы

### Запуск

- Мини-игра запускается либо автоматически по сюжетному триггеру, либо при клике на интерактивную точку во время свободного перемещения. В обоих случаях открывается UI-окно мини-игры.

### Прохождение

- Игрок взаимодействует с механикой до выполнения условия победы или поражения
- Нажатие кнопки "Skip" в интерфейсе пропускает мини-игру и ведет к экрану поражения

### Результат

- Если игрок не набрал нужное количество очков или потратил все попытки, запускается экран поражения
  - воспроизводится звук `minigame_failure`
  - игрок выбирает из опций попробовать снова (retry) или пропустить (skip).
- Если игрок выполнил победное условие, запускается экран выигрыша
  - воспроизводится звук `minigame_success`
  - игрок кликает на продолжение (next) чтобы перейти из игры обратно в нарратив
- Победа или поражение в мини-игре передает информацию шкалам ATT и SUS, на экране статов обновляется количество побед.
- В тренировочном режиме результат сравнивается с лучшим и обновляется в таблице рекордов.

### Логика таблицы рекордов (для мини-игр на ферме)

- Текущий результат игрока динамически обновляется в таблице: плашка с его именем встраивается в таблицу рекордов NPC.
- Когда игрок достигает 1 место, открывается соответствующий адалт-статик справа

# Механика "Стрельба"

## Общая информация

UI мини-игра на точность в формате light gun / shooting gallery. Игрок перемещает дрожащий прицел по экрану и нажимает выстрел при наведении на статичные или движущиеся цели. В зависимости от тайминга выстрела и положения прицела, игрок получает разное количество очков. Базовая механика едина для всех вариаций, но меняются цели, условия и последствия попаданий.

## Схема UI (Общая)

### Игровое поле

- Фон: статичное изображение или видео
- Камера фиксирована
- Прицел в виде перекрестия
  - Внутри — красная точка (зона точности)
- Прицеливание происходит в пределах поля (темно-серая зона), при выходе курсора из этой зоны прицел становится обратно курсором без дрожания для взаимодействия с UI-элементами

### Цели

- Статичные или движущиеся объекты (бутылки, банки, стаканы)
  - common/обычные: базовый цвет, без эффектов
  - uncommon/ценные: различия в цвете, могут слегка мерцать
  - rare/редкие: контрастный цвет, эффекты

### Дополнительные UI-элементы

- Полукруглый таймер, время дублируется в секундах (в соревновательных режимах)
- Счётчик
  - Для попаданий в формате кол-во попаданий/цель, например 8/12
  - Для очков в формате кол-во очков / цель, например 1230/5000, либо просто кол-во очков
- (опционально) комментарии-эффекты для попаданий, которые появляются рядом с целями
  - "Combo" (попадание в 5 целей подряд)
  - "Nice shot!" (попадание в ценную цель)
  - "Lucky shot!" (попадание в редкую цель)

## Принцип работы

### Движение прицела и дрожание

- Игрок управляет прицелом с помощью мыши: прицел привязан к курсору
- Внутри прицела красная точка отклоняется от центра по плавной случайной траектории. Точка остаётся привязанной к прицелу и не выходит за пределы допустимого радиуса
- Параметры дрожания могут изменяться:
  - амплитуда: предсказуемая траектория, по которой движется точка; может удаляться от центра больше или меньше
  - скорость с которой движется точка: может быть быстрее или медленнее

Игрок компенсирует дрожание, стараясь нажать выстрел, когда точка находится у центра.

### Выстрел / попадание

- При нажатии левой кнопки мыши фиксируется позиция прицела
  - если точка находится вне цели → промах, 0 очков
  - если точка поверх цели → попадание, заданное целью количество очков
  - если точка поверх цели и в центре курсора (отклонение от центра до 20%) → идеальное попадание, +50% очков от полученных

### Виды целей

- Статичные цели находятся на одном месте всю игру и исчезают при попадании на них
- Динамические цели двигаются по заранее заданной траектории (например слева направо, сверху вниз, волнообразное движение с отклонением по вертикали)
  - скорость и тип движения настраиваются
  - цели исчезают при попадании на них
- Цели делятся на три категории:
  - common/обычные: появляются часто, дают базовые очки (100)
  - uncommon/ценные: появляются реже в 4 раза (примерно 1 на каждые 4 обычные цели), дают x2 очков
  - rare/редкие: появляются 1-2 раза за игру, имеют менее предсказуемую траекторию, более высокую скорость, дают x10 очков

### Окончание игры

Игра заканчивается при выполнении одного из условий:

- Игрок победил: набрал необходимое количество очков или совершил нужное количество попаданий
- Истекло заданное время
- На экране не осталось целей (заранее заданное количество целей прошло)

## Вариации мини-игры

### Обучение девушки стрельбе — Grace Shooting Training

Игрок помогает Грейс тренироваться, стреляя по движущимся бутылкам и банкам за ограниченное время.

- Цели движутся по простым траекториям
- На фоне проигрывается видео с Грейс (несколько состояний, простые анимации с фокусом на зад)
- Итоговая точность определяет сцену после мини-игры

### Стрельба на ферме — Shooting Range

Классический shooting gallery режим в свободном перемещении

- Игрок сбивает максимальное количество движущихся целей за ограниченное время
- Цели появляются и двигаются по заданным траекториям
- Ведётся подсчёт очков
- Возможна таблица рекордов

Вариация со статичными предметами и изменяемым состоянием игрока:

- Игрок целится и бросает шарик в выбранный стакан:
  - Попадание → пьёт девушка
  - Промах → пьёт ГГ
- С каждым промахом увеличивается дрожание прицела
- Игроку нужно попасть в нужное количество стаканов до достижения критического уровня опьянения
- Результат влияет на сцену флирта после мини-игры

# Механика "Борьба"

## Общая информация

Мини-игра на реакцию. На экране поочерёдно появляются индикаторы, указывающие, какую кнопку мыши нужно нажать: левую (ЛКМ) или правую (ПКМ). Игрок должен быстро распознавать команду и ритмично нажимать правильные кнопки в заданное окно времени. Правильное нажатие добавляет очки, неправильное приносит штрафы. Цель — набрать нужное количество очков или сделать достаточно правильных попаданий за ограниченное время.

## Схема UI (Общая)

### Основной UI

- Поле, внутри которого регистрируются нажатия (кнопка пропустить и другой доп UI отдельно от него)
- Индикаторы команд, сигнализирующие действия:
  - Синий — ЛКМ
  - Красный — ПКМ
  - Индикатор нейтрального цвета для показа между основными
  - Каждый индикатор имеет таймер (1–2 секунды), который визуализирован сужающимся к центру кругом
  - При клике индикатор пульсирует и с эффектом сменяется на следующий

### Дополнительный UI

- Таймер отсчёта времени раунда
- Счётчик очков — текущий результат, растёт при правильном нажатии
- Комментарии, которые появляются при успешных действиях: "Nice punch!", "Combo!", "On fire!"
- Кнопка пропуска или закрытия

## Принцип работы

- Рандомные индикаторы действий (ЛКМ или ПКМ) появляются поочерёдно в специальной зоне экрана.
- Каждый индикатор активен ограниченное время и содержит окно точного тайминга.
  - Стандартный тайминг индикатора: 1.2 сек → уменьшается до 0.6 сек (можно настраивать)
- Игрок должен нажать соответствующую кнопку мыши в пределах этого тайминга
- Результат нажатия определяется точностью:
  - Perfect (центр тайминга, когда круг таймера идеально совпадает с границами индикатора) → максимальные очки / бонус
  - Good (чуть раньше или позже центра, внутри окна тайминга) → базовые очки
  - Неверная кнопка / пропуск → штраф (зависит от контекста)
- После каждого ввода либо истечения таймера появляется нейтральный, а затем следующий индикатор.
- Темп и сложность постепенно увеличивается.
- Игра продолжается до выполнения условия завершения:
  - достигнуто нужное количество очков / попаданий
  - истекло время

## Вариации мини-игры

### Скрытный адалт с Ханной — Hannah Adult Fighting

ГГ действует скрытно, стараясь не создавать лишнего шума, пока Джейсон находится за стеной.

- ЛКМ и ПКМ как чередование активных действий и поддержания контроля
- Правильные действия продвигают адалтные стейты
  - Прохождение всех стейтов открывает адалт полностью и ведет к победе
- Ошибки увеличивают уровень подозрения
  - Если подозрение достигает максимального значения, адалт заканчивается раньше и ведет к проигрышу

### Тренировка с манекеном на ферме — Fighting Training

Игрок тренируется на манекене с фото Джейсона, выполняя серии ударов в ритме.

- ЛКМ и ПКМ как разные руки
- Игроку нужно совершить как можно большее количество правильных ударов за ограниченное время
- Скорость ритма постепенно растёт
- Попадания увеличивают счёт, ошибки уменьшают количество оставшегося времени
- Возможна таблица рекордов

### Борьба девушек в грязи — Mud Fighting

Игрок помогает Эмили либо Рокси во время их борьбы в грязи на фестивале.

- ЛКМ и ПКМ как атака и уклонение
- У каждой девушки есть шкала здоровья:
  - Успешная атака → наносит урон сопернице
  - Успешное уклонение → предотвращает получение урона
  - Ошибка (неверная кнопка или пропуск) → наносит урон девушке ГГ
- **Победа:** шкала здоровья соперницы опустошается первой
- **Поражение:** шкала здоровья выбранной девушки опустошается

# Механика "Контроль"

## Общая информация

Мини-игра на удержание баланса. На экране отображается вертикальная шкала, которую игрок заполняет, удерживая левую кнопку мыши (ЛКМ). В процессе заполнения шкала периодически переходит в напряжённое состояние и меняет цвет. В этот момент игрок должен отпустить кнопку, чтобы избежать перегрузки. Пока кнопка отпущена, шкала постепенно опускается. Задача игрока — контролировать ритм удержания и отпускания, чтобы довести шкалу до максимума за отведённое время.

Механика едина для всех вариаций, меняется только визуальный и нарративный контекст.

## Схема UI (общая)

- Шкала баланса (вертикальная) в разных состояниях:
  - нормальное (белая/золотистая)
  - напряжение (оранжевая)
  - критическое (красная)
- Круговой таймер
- Счётчик прогресса
- Кнопка пропуска / выхода

## Принцип работы

Игрок зажимает левую кнопку мыши — шкала заполняется. Когда шкала переходит в напряжённое состояние и меняет цвет — кнопку нужно отпустить, иначе прогресс начинает убывать. Пока кнопка отпущена шкала медленно опускается. Как только состояние возвращается в нормальное — снова зажимаешь и продолжаешь заполнять.

**Победа и поражение:** Победа — шкала достигла максимума до истечения таймера. Поражение — таймер истёк и шкала не заполнена до нужной отметки.

**Сложность:** В тренировочном режиме напряжённое состояние появляется редко и держится недолго. В сюжетном — чаще. В адалт-версии с Ханной частота и длительность напряжённого состояния нарастают по мере развития сцены.

**Счёт:** Результат измеряется временем — как быстро игрок заполнил шкалу до максимума. В тренировочном режиме лучшее время сохраняется и переводится в очки для счёта фестиваля.

### Заполнение шкалы

Игровой процесс строится на ритмичном чередовании удержания и отпускания.

- Игрок удерживает ЛКМ — шкала заполняется.
- В случайные моменты шкала переходит в напряжённое состояние и меняет цвет на оранжевый. В этот момент игрок должен отпустить кнопку.
  - Пока кнопка отпущена, шкала постепенно опускается вниз.
  - Если игрок продолжает удерживать кнопку и шкала переходит в критическое состояние (красный цвет), начинается короткий отсчёт (до 1 секунды).
  - Если кнопку не отпустить в течение этого времени, происходит провал.
- После возврата шкалы в нормальное состояние игрок снова может удерживать кнопку и продолжать заполнение.
- В начале напряжённое состояние возникает редко и длится недолго. По мере развития тренировочного раунда оно появляется чаще и требует более быстрой реакции.

### Победа и поражение

- Победа — шкала достигла максимального значения до истечения таймера.
  - В режимах с повторяемым циклом каждая полностью заполненная шкала засчитывается как один успешный этап и добавляет +1 к счёту. Лучшее непрерывное комбо отражается в таблице рекордов.
- Поражение — игрок удерживал кнопку в критическом состоянии слишком долго, либо время истекло, а шкала не была заполнена до конца.

## Вариации

### Доение домашних коз — Goats Balance

Тренировочный режим в амбаре. Игрок последовательно доит несколько коз. Каждая следующая коза требует более точного контроля. Ошибка в критическом состоянии завершает текущую серию. Возможен подсчёт рекорда по количеству успешно выполненных циклов подряд.

### Доение Рокси — Roxy Milking Balance

Нарративно день 2. Та же механика, но контекст фетиша доения. Результат влияет на развитие адалт-сцены с Рокси.

### Управление механическим быком — Mechanical Bull Balance

Адалт 3 с Ханной, День 7. Ханна на механическом быке. ГГ управляет движением быка — задача чтобы бык двигался, принося ей удовольствие, но не скинул ее с себя полностью.

# Механика "Реакция"

## Общая информация

Мини-игра на менеджмент. На экране появляются активные зоны, каждая из которых проходит три стадии: зелёная — подготовка, жёлтая — основное время, красная мигающая — критическая фаза. Игрок кликает левой кнопкой мыши внутри зоны заполняя круговой прогресс. Полностью обработанная зона даёт максимум очков, частично — меньше, пропущенная — ничего. Одновременно на экране может быть несколько зон — игрок сам расставляет приоритеты. Цель — набрать нужное количество очков до истечения общего таймера. Механика одна для всех вариантов — меняется только визуальный контекст.

## Схема UI

- Игровое поле — локация в виде статичного или слабо анимированного фона
- Зоны взаимодействия — круглые области по которым нужно прокликивать
  - Круговой прогресс-бар по контуру
  - Цвет зоны меняется по стадиям: зелёный → жёлтый → красный мигающий
  - Пунктир перед тем, когда зона станет активной
- Общая шкала прогресса / таймер раунда
- Счетчик очков
- Кнопка пропуска или выхода

## Принцип работы

- Игрок видит общий таймер в виде растущей шкалы, при его заполнении игра заканчивается
- Новые зоны для кликов появляются каждые несколько секунд (интервал настраивается)
  - Одновременно активно до трёх зон
- У каждой зоны свой внутренний таймер (настраивается) — когда он подходит к концу, зона начинает мигать, затем исчезает
- Если игрок кликает внутри зоны — вокруг неё появляется и растёт прогресс-бар. Таймер зоны при этом не останавливается
- Когда таймер зоны завершен:
  - Прогресс заполнен полностью → очки удваиваются, зона исчезает по достижению 100%
  - Прогресс заполнен частично → обычные очки (например процент прогресса x10)
  - Игрок не кликал → зона исчезает без результата

### Победа и поражение

- Победа — набрано нужное количество очков до истечения общего таймера
- Поражение — таймер истёк без достаточного прогресса

### Прогрессия сложности

- Чем сложнее режим — тем чаще появляются зоны и тем меньше времени на обработку каждой
- В расслабленных вариациях (мытьё машины, адалт) — зоны редкие и долгие
- В напряжённых (тренировочный режим) — частые и короткие

Референс: quick-time events в играх с катсценами, но зон несколько одновременно.

## Вариации

### Быстрое действие: Трактор — Tractor Reaction Event

В нарративе День 3. ГГ едет с Эмили на тракторе, который иногда барахлит. Игрок устраняет неполадки кликами, при успехе адалт продвигается, при неудаче они во что-то врезаются и адалт заканчивается раньше/без дополнительных статиков.

### Быстрое действие: Мытьё машины — Car Wash Reaction Event

В нарративе День 4. ГГ и Рокси моют машину. Зоны — грязные пятна на кузове. Игрок оттирает их кликами. Расслабленный темп — зоны появляются медленнее и держатся дольше чем в других вариантах. Результат влияет на сцену с Рокси.

### Быстрое действие: Тренировка — Reaction Training

Свободное перемещение: ГГ ездит на тракторе, уклоняясь от препятствий (или типа косит поле).
